# 发布可发现对象的验收材料

`common/` 中的 Schema 由本组用例选择，通过公开 Writer 一并发布；不是生产源码或系统对象类型登记表。
`image/`、`module/`、`table/` 共用说明结构和同一个 Inspection Interface，处理器没有安装。
说明中的资源定位形状只是本组发布者采用的普通值，系统不据此读取资源、安装处理器或发权。

`resources/` 是墙外 Snapshot 夹具的输入，不传给知识 Writer。图片原始字节、分散源码、测试向量和
另一仓的许可证各自有固定版本；外部表的来源在用例中返回不可用。说明与能力声明仍可发布、固定读回
和按 Schema 字段 access 发现。令牌占位只由测试替换为实际仓、提交和故障来源。

场景宿主的具名 Go evidence 负责公共 Client/Server 操作及后态断言，不把资源文件名解释为 ObjectID。
