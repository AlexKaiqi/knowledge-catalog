# 知识地址

一次精确读取或维护所指向的知识单元，由对象标识与可选切面名、成员键表达。

现行 Address 种类包括 Entity、Aspect、Relation、Member，历史文件也可能使用 Record。完整知识引用还包含仓身份，地址不由 Dataset 交付目录生成。

相关说明：[对象](../object/definition.md)、[切面](../aspect/definition.md)、[成员](../member/definition.md)、[关系](../relation/definition.md)。
