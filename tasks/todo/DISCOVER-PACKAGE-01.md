# DISCOVER-PACKAGE-01 · 可选发现包：给任务，出命中对象

## 目标

提供一个可选的发现包：调用者给任务说明、Dataset（可不给）和预算，得到命中对象，结果形状与 search 一致，
带命中坐标与 Dataset 修订、每个命中由哪些原语调用得来、是否完整及原因。只给命中，不给回答。

发现包只用公开原语、以调用者身份执行；内部实现不限，首版用规则编排即可，实现带版本。任务说明作为意图、
每一步作为轨迹进入使用记录，与调用方自己编排原语的数据进入同一套汇总。

## 依据

- [发现](../../doc/design/discovery.md)：发现包（可选）、访问原语、完整性、使用记录。
- [权限](../../doc/design/permissions.md)：Dataset 消费权限。

## 验收

- `discovery.md` 为发现包补用例编号，场景树里有关联规格并全绿。
- 同一任务、同一 Dataset 修订，发现包给出的每个命中都能由调用者按同一版本回读，依据里的原语调用能复现。
- 调用者没有消费权的 Dataset 不出现在选择和结果里；发现包没有调用者自己做不到的读取。
- 原语报的未声明、不支持、未就绪、不完整照实出现在结果里；超预算明确报告。
- 使用记录里能看到任务说明、每一步原语调用和实现版本。
- `make check-docs`、`make quality`、`make test` 通过。
