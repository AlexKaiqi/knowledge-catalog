# INDEX-PHYSICAL-01 · 索引物理布局重构（待审查）

## 目标与依据

必交付：生产索引的持久资源保护与回收闭环，以及未变化成员计算产物的复用，包括避免重复向量计算。
直接共享查询结构为可选扩展，经等价性与成本审查后决定是否纳入；未纳入时继续使用独立 Dataset 语料。

设计依据为[索引物理布局](../../doc/design/index-physical.md)；检索语义、保留与清除、外部观察分别沿用
[发现](../../doc/design/discovery.md)、[Dataset](../../doc/design/dataset.md)、[LiveAccess](../../doc/design/liveaccess.md)。
完整固定读取依据与状态比较沿用[对象版本与读写](../../doc/design/object-versioning.md)，不另造对象版本定义。

## 实施前待定

以下决定形成审查结论后才能实施；协议形状落实到所属公开接口与契约，不在本文预设字段或状态机。

| 决定 | 必须明确的内容与依据 |
|---|---|
| 引用权威与发布交接 | 谁持有修订引用、构建保护和删除排他；准备结果如何跨过 Dataset 发布与引擎提交点；发布成功但交接未确认、发布结果不确定、进程退出、保护过期和重试时如何恢复。给出支持的工作进程部署方式、关键故障时序及旧资源迁移与回退方式 |
| 写入隔离与删除完成 | 所选载体如何约束资源创建、暂存产物转为可复用资源及迟到写入，证明过期构建者不能重建已确认删除的资源。明确删除依据的持久保留与清理条件、暂存资源的确权与有界清理，不以禁止发布代替物理写入隔离 |
| 观察代与查询保护 | 落实设计中的观察代续页截止时间及其与 Dataset 宽限的组合；明确期限和在途请求保护由谁持久保存、如何恢复与释放。覆盖同修订连续刷新、修订随后被替换，以及续页到期时仍有在途请求 |
| 完整依据与证据保留 | 接入对象层的完整候选来源、选择范围、来源绑定及解释依赖，区分产物贡献者与修订读取依据；确定请求证据独立保存还是引用实际共享数据，明确引用接管、释放及回收核对方式，不把有效读取依据或证据绑定到整套查询结构的寿命 |
| 复用产物与构建身份 | 确定要保存的转换结果与已生成向量、由谁保存与加载、怎样绑定成员构建版本及实际依赖。证明同键改定义不会串版；容器重写仍能复用兼容值；模型调用计数能验证向量复用 |
| 消费者与物理布局 | 用查询、准备、恢复的调用证据决定哪些来源投影保留。比较产物保存与对象物化的成本；若纳入直接共享，首批仅考虑输入、成员和统计范围一致的静态单来源全选，明确不满足条件时的独立准备路径 |
| 成本与空间收敛 | 分别确定成员计算复用的收益目标与语料物化的写入、空间、分片和延迟阈值；单对象变化与连续观察刷新必须入样，不能用模型调用减少掩盖全量物化超标。未达目标时先调整物化方案或明确取舍；明确共享成本的配额归属、构建峰值、残值压缩触发及回收时限。涉及 ANN 结构变化时先确定召回质量标准 |

## 任务衔接与前置

| 既有任务 | 本任务使用的交付与责任边界 |
|---|---|
| `OBJECT-VERSIONING-01` | 共同审查后先交付“固定读取依据交付”，作为本任务生产实现接入的前置；本任务将成员产物、查询代与观察代绑定到该依据。无变化命令、比较和历史继续由对象任务交付，按实际交叉场景在同一候选上联合验证，不要求整项先结束 |
| `INDEX-SEARCH-SPACE-01` | 保留其成员增量、成员隔离、语料恢复和观察发布责任；本任务接入产物复用及资源保护。构建版本、统计隔离与发布接缝的重叠修改在同一候选上验证 |
| `DATASET-RETENTION-01` | 消费其检索保留、退役和续页宽限判定，完成物理引用释放及安全删除；替换固定三分钟删除仍与该任务共同验收，不另设保留策略 |
| `DATASET-STORAGE-01` | 接入其配额与紧急清除，联合验证共享结构、候选峰值和观察证据清除；来源提交保留归该任务 |
| `ACCEPT-HARNESS-01` | 测试命名空间与残留由其负责；生产回收只接管已确权资源 |

审查不依赖上述任务全部结束；开工须具备所用接缝，缺失部分由所属任务交付。需要调整归属时同时更新双方
前置与验收。修改构建取消链路前核对 `DEBT-MAINTENANCE-CANCEL-01` 的当前交付与剩余验收。

两个重构先共同确定完整依据的解析与保留接缝，以及读取依据、请求证据和查询资源各自的保护责任。
索引的消费者分析、资源权威与故障时序审查可先进行；生产实现接入与物理布局切换须等
`OBJECT-VERSIONING-01` 的“固定读取依据交付”有实现和回归证据，不用临时 pin 或自定义版本模型顶替。
此后本任务与 Object 剩余不重叠工作可以分别推进，共同接口变化须同步双方实现与联合验收，
不互以对方整项完成为前置。

本任务不等待 ARCH；按当前合法装配边界完成资源管理与恢复，再由 ARCH 对稳定接口做目录归位。
`ARCH-HOME-CONFIG-01` 只有在共同审查后确认无配置重叠，或所需新增持久状态/恢复配置已交付时才可穿插。
需要修改相同文件时主线批次先稳定，不为迁移暂停未完成的行为设计。

`DEBT-DATASET-STATE-ACCEPT-ATOMIC-01` 已交付同进程的[修订围栏](../../snapshot/dataset/revision_fence.go)，
本任务复用它，不重新领取观察接受修复；该围栏与 registry CAS 均不能单独证明跨存储的引用交接和删除安全。

## 实施次序

先完成共同接口审查，并确认消费者、资源身份与引用权威；Object 固定读取依据基础交付后，
接入该依据、持久保护和安全对账。新机制完整接管前不批量删除旧索引，无法确权
的资源保留并报告。随后接入成员产物复用与物化成本观测，处理聚合全文和统计的更新。直接共享若通过审查，
最后与独立语料对照后开放。各阶段均保留旧修订及有效续页所需依据，迁移中断后可恢复。

## 索引接入与接口稳定交付（2026-10-20）

本交付点供 ARCH 的 DatasetPin、仓管理及应用执行迁移使用，须同时满足：

- 已消费 Object 的固定读取依据实现；准备、发布和查询回读使用同一合同，
  产物贡献者不替代完整候选来源与依赖，实际消费者及转换边界有明确 owner。
- 本轮要迁的发布交接、资源保护、恢复、释放与装配接口已经实现；
  对应持久配置及生命周期职责确定，不能把未实现的恢复口留给 ARCH 在搬迁时补齐。
- 同一候选上的固定依据回读、来源或依赖推进、发布失败/恢复及受影响资源保护回归通过；
  记录候选、实际接口、已验场景和剩余项。索引回收后读取依据与观察证据的独立保留，
  按本任务与 Object 的联合验收中适用场景验证，不以接口签名冻结代替行为验证。
- 迁移清单中的接口没有尚待决定的行为；后续产物复用、可选共享或优化若仍会改这些接口，
  相应迁移继续后置。未涉及的可选扩展或整项性能验收不一概阻塞已经稳定的目录部分。

达到本交付点及 Object 固定读取依据交付后，ARCH 仍按各子任务前置执行；
Invocation 中比较、无变化写入和历史操作另等 Object 对应批次交付。
本交付点不表示索引整项验收通过，未完成的性能、真实引擎和生命周期验收继续保留原要求。
本次只登记推进与放行条件，尚未完成任何交付点。

## 验收

| 场景 | 结果要求 |
|---|---|
| 构建超过宽限、准备后未发布、发布成功但引用交接未确认或发布结果不确定，各处进程退出与重试 | 有效候选与已发布资源始终受保护；失效候选最终释放，过期构建者不能继续发布；恢复不依赖进程内定时器 |
| 发布取得引用与回收并发；删除前后重启；引用枚举失败或归属未知 | 待删除资源不会成为新发布依据，删除幂等恢复，未知不当空集合，未确权资源不删 |
| 暂停构建者或延迟物理写入，待保护过期、回收执行后再恢复；其间重启协调进程 | 已确认删除的资源不被旧写入重建；未能排除迟到写入时不清理删除依据或报告完成；暂存资源可确权并按约定清理 |
| 多修订共享后依次解除引用，停止来源投影需求 | 最后保护与宽限结束后回收，后台不重新生成已释放资源；仍有消费者的投影可继续准备与恢复 |
| 新修订的成员有效输入未变、重启后用未变产物物化新语料、只改查询权重 | 未变且兼容的成员不重复计算或调用模型，复用不依赖内存缓存；新修订仍有自己的依据，整对象/整容器物化单独计量 |
| 新增成员、同键改模板、Schema、模型版本或构建配置 | 只计算受影响成员，新旧修订分别引用正确产物；相同成员键不能掩盖依赖变化 |
| 单对象仅选 public，private 含独有词；跨仓组合同一对象 | 排除输入不进入构建值或候选，保留正确来源向量，与按选入范围独立构建的结果一致 |
| 撤下全文成员或选用共享统计中的成员子集 | 残值不影响匹配、归因和 top-k，压缩按约定收敛；无法证明隔离时重新物化查询结构 |
| 当前修订刷新外部观察，旧修订仍保留 | 观察依据不串版，静态复用不隐式共享可变观察 |
| 同一修订连续替换观察代，随后发布新修订；跨期限续页、在途请求和进程重启 | 新查询使用该修订绑定的观察代；旧续页在两个适用宽限均有效时保持原依据，到期明确拒绝，刷新、续页和修订切换均不延长旧观察代期限；重启不丢保护，已取得保护的在途请求完成或期限结束后才释放；保留修订只长期保护最后采用的观察代，更早代在最后保护解除后回收 |
| 检索到期、续页宽限、退役、紧急清除及候选超配额 | 联合既有生命周期任务验证：物理释放服从权威判定，清除不被残值策略推迟，准备失败不破坏旧版 |
| 若纳入直接共享：与独立语料对照，并使共享条件失效 | 满足设计中的等价性要求，固定语料不随 HEAD 漂移；不满足共享条件时能独立准备 |

精确、近似检索及预算不足分别按设计的判据验证，不把 ANN 或部分集合逐项相同作为验收条件。
按[压测合同](../../.data/scale/CASES.md)记录环境与规模，分别覆盖 Writer 无变化命令、Dataset 幂等重放、新修订但成员输入未变、
单对象变化、单成员新增/修改/退役、连续观察刷新及共享来源，
测量成员计算、模型调用、写入对象与字节、稳定和峰值空间、索引与分片数、发布耗时与查询延迟，按审查确定
的阈值判断收益。复制全部旧值只能证明减少重算，不能报告避免全量物化。

共同门禁按[任务约定](../README.md)执行；另须有目标 OpenSearch 实例上的排序、写入量、重启和回收证据，
夹具不能代替真实引擎结论。生命周期联合验收仍走对应任务的真实部署入口。

### 与对象版本重构的联合验收

本表由本任务维护，`OBJECT-VERSIONING-01` 共同执行。本任务验证复用、模型调用、检索依据与回收；
对象任务验证本地状态、完整回读、命令结果及历史，两边使用同一组来源与变更。证据复核按 LiveAccess
合同执行；涉及保留、退役或清除时共同接入对应生命周期任务。

| 场景 | 联合判定 |
|---|---|
| 同一 Unit 未索引字段变化；本地引用不变但 Schema 解释或外部值变化 | 前者状态摘要变化而未受影响成员复用；后者本地摘要可不变，但按有效输入及依赖核对并重算受影响成员。模型配置变化另验构建身份，不用对象摘要决定复用 |
| A 仓贡献定义，B 仓在旧修订无该对象的方面，新修订新增方面；选择规则不变 | 旧依据仍包含 B 的固定候选版本，缺失可复核；新修订保留完整新依据，仅受新增输入影响的成员重算；复用产物不带入旧范围或来源 |
| A → B → A，分别保留或合法回收第一个 A 的产物 | 仍可引用且兼容时复用，否则重新计算并取得新物理资源身份；命中绑定第三次来源提交、当前 Dataset 修订和本次观察，历史保留实际两次变化 |
| 查询生成代及旧观察查询结构到期回收，读取依据和请求证据仍有效；随后重启 | 在当前授权、绑定及来源和依赖可用时，本地固定回读成功；原观察按有效证据及其访问合同复核，不重新外呼来源。过期搜索与续页拒绝，证据独立保留不保护整套查询结构；证据到期、撤权、退役和紧急清除另按各自合同验证 |
| Writer 无变化命令、同一 Dataset 发布的幂等重放、新修订但成员有效输入未变 | 分别核对原提交及无推进通知、原发布结果、新修订依据与兼容产物复用，不人为制造提交或修订；无仓推进通知期间的外部刷新、能力变化核对和丢失资源恢复仍按有效需求执行 |

## 不做

不新增 Dataset 保留策略、来源提交保留或自动发布；不清除来源仓历史。不纳入多来源查询合并、
外部观察查询结构的直接共享或全局物理池；证据对本次观察值的独立引用仍须按保留合同处理。
不向调用者暴露物理索引选择或拼装步骤。
