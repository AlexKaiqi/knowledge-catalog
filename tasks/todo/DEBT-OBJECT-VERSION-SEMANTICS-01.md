# DEBT-OBJECT-VERSION-SEMANTICS-01 · 统一对象状态摘要与读取版本的定义

## 债

- 位置：`doc/concepts.md` 的 Object Version；`doc/design/object.md` 的读取；
  `doc/design/object-versioning.md` 的比较状态与范围。
- 信号：核心概念称跨仓对象只有一个全对象摘要，读取设计把对象版本称为各方面版本的组合，
  新提案则定义特定范围内的本地状态摘要，且允许部分读取。
- 判定：2026-10-20 静态审查确认，三者回答不同问题。D1 仅交付 A、D2 交付 A+B 时，
  两边均完整授权也不能产生同一个无范围限定的对象版本；状态摘要也不能标识 A→B→A 中的两次修订。
- 处置：以采用后的设计统一核心概念与引用文案，明确状态比较的范围、固定读取坐标和修订历史；
  用自动文档守卫或合同保护已在多处出现的术语混用，避免只靠人工约定。
- 触发条件：`OBJECT-VERSIONING-01` 开工时并入。

## 目标

调用者能判断哪项依据用于状态比较、哪项用于精确回读、哪项用于辨认历史修订，
不把局部状态摘要当作全局唯一版本或写入条件。

## 依据

- [核心概念](../../doc/concepts.md)。
- [对象](../../doc/design/object.md)：读取与对象引用。
- [对象版本与读写](../../doc/design/object-versioning.md)：比较的状态与范围。

## 验收

- 三处文档采用一致定义，不再无条件承诺跨仓对象存在一个全局完整摘要。
- 同范围状态比较、不同 Dataset 范围、部分读取和 A→B→A 的例子能够同时成立。
- 自动检查保护采用后的区别，重读变更文档并通过 `make check-docs`；涉及代码的合同通过相应回归及 `make quality`。

## 前置

对象版本设计审查决定采用的概念边界。

## 设计修订（2026-10-20）

本轮统一概念与设计中的三项依据：范围限定的本地状态摘要、固定来源及依赖的读取坐标、辨认变化的修订历史。
同一选择规则下 Unit 集合改变属于状态变化；不同来源或选择规则之间不能直接比较摘要。
这项记录只覆盖设计修订，自动守卫与实现合同尚未完成，本债保留待做。

## 不做

不凭改名替代语义定义，不新增跨仓事务或按摘要反查内容。
