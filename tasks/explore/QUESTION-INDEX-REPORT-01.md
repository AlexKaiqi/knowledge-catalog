# QUESTION-INDEX-REPORT-01 · 问题索引与已排除清单

## 要回答的问题

本轮确认了哪些问题、分布在哪些模块与维度、哪些原疑点经复核不成立、哪些信号已升级为守卫。

## 已知证据

已排除的疑点至少三条：`relations` 与 `traverse` 计数一致（对照基线）；
`traverse --max-hops` 上限 1-8 已在 help 声明，"无上限说明"不成立；
`--limit 0` 属文档语义未写清而非越界未校验。

任务书预期分级分布为 P0 0-2、P1 5-8、P2 15-20、P3 10-15，实际分布需对照。

## 判定标准

- 索引表列出每个已确认问题的 ID、模块、维度、分级、承接到哪个任务；状态以 `tasks/` 目录为准，
  不另维护状态字段。
- 已排除疑点逐条记录原疑点、复核方式、排除依据，避免同一疑点被反复重开。
- 升级为守卫的信号单列，标明守卫所在测试文件与反例构造方式。
- 若 P0 为 0，须写明已做的验证动作，不用"无严重问题"一句带过。

## 前提

各探索任务产出 `## 结论` 后汇总；本项不阻塞它们，只在其结论变化时同步。

## 不涉及

不重复问题正文与复现步骤；不另建状态字段；不新增 `kc-audit/` 目录或绕过 `check-docs` 白名单。
