# DEBT-INDEX-RELATION-CURSOR-01 · 关系分页游标跨进程恢复

## 债

- 位置：`declarativeindex/projection/relation_continuation.go`、`dataset_relations.go`、`relations.go`。
- 信号：外层关系游标的 HMAC 密钥在进程初始化时随机生成；同一受保护语料仍存在，另一进程也无法验签。
  Dataset 关系入口先打开当前生成代，再按当前代校验旧游标，维护替换后不能选择原代。
- 判定：与索引物理重构要求的原语料续页、重启后恢复和持久宽限不一致；提供方已有的续页保护不足以修复外层。
- 处置：立即并入 `INDEX-PHYSICAL-01`，同批完成持久验签/原代绑定及回归；保留当前防篡改保证。
- 触发条件：`INDEX-PHYSICAL-01` 已在进行，且正修改同一索引分页接缝。

## 目标

有效关系续页在重启和维护替换后仍选择原受保护语料；期限不被后续请求延长，伪造范围或失效引用明确失败。

## 依据

- [索引物理布局](../../doc/design/index-physical.md)、[发现](../../doc/design/discovery.md)。

## 验收

- 实际 Dataset 关系首屏后替换生成代，冷开实例仍按原固定内容继续；截止后拒绝新续页。
- 变更查询、范围或签名均拒绝；签名材料缺失/不可读不能回退进程新密钥或活动语料。
- 受影响 race、架构合同、`make check-docs` 和 `make quality` 通过，不削弱现有关系分页断言。

## 前置

并入 `INDEX-PHYSICAL-01` 的持久资源与查询/续页保护批次。

## 不做

不改变关系语义，不用公开可重算校验值替代原防篡改保证，不把文件读取权推成来源历史权。

## 关闭

登记后立即并入已在进行的 `INDEX-PHYSICAL-01`；此为归并关闭，不表示缺陷已修复或验收通过。
实现与完整回归由该主任务继续交付。
