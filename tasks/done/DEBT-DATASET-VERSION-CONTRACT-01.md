# DEBT-DATASET-VERSION-CONTRACT-01 · Dataset 新版本合同缺实现与验证入口

## 债

- 位置：`doc/design/dataset.md` 的 U16、U17，`.data/scenes/_views.yaml` 的 Dataset 产品视图。
- 信号：2026-10-20 完整契约的 `TestSceneViews/product_links` 报两条新设计用例既无实际验证关联，也无明确 gap。
- 判定：设计目标新增了服务端版本号分配、无变化定义不增号和发布版间指针对比；当前 CLI 仍要求显式 revision，不能把旧发布测试当作完整新合同证据。
- 处置：产品视图先登记精确 gap；实施前审查版本分配、重放与对比入口，再补具体规格、实现及场景关联，不削弱设计或守卫。
- 触发条件：下一次修改 Dataset 版本分配、发布幂等或历史对比入口时处理；与 Dataset 修订任务有文件重叠时按任务规则并入。

## 核实（2026-10-21）

债仍然成立，性质是新功能而非缺陷：U16（服务端版本号分配、单调不可复用、同定义重放不增号、
请求内固定版本）与 U17（两版指针对比，不读来源字节）都缺公开入口，当前 CLI 仍要求显式 revision。

`.data/scenes/_views.yaml` 已按债的处置为 U16/U17 登记精确 gap，指向本债，因此产品视图侧没有“无关联
也无 gap”的悬空条目；未做的是实现与语义回归。本轮不改：这需要新增版本分配与对比的协议入口
（公开 API、Schema、Conformance 同步），属新功能，而当前优先级是 bug 类任务。

去向：与 `DATASET-REVISION-01` 的范围重叠审查后并入，避免同文件双线实施。触发条件不变——
下一次修改 Dataset 版本分配、发布幂等或历史对比入口时处理。

## 目标

Dataset 的版本分配、无变化发布与两版指针对比满足 U16、U17，并有对应的具体执行证据。

## 依据

- [Dataset](../../doc/design/dataset.md)：版本、元数据、U16、U17。
- [工程质量闭环](../../doc/engineering/quality.md)：质量问题三个出口。
- [场景合同](../../.data/scenes/README.md)：新增产品条目须有验证入口或明确缺口。

## 验收

- U16 的服务端分配、单调不可复用、同定义重放不增号及请求内固定版本各有可证伪回归。
- U17 比较两份已接受清单的增删改与元数据，不读来源字节；来源不可用仍返回指针差异及明确状态。
- 具体验证关联到产品条目，已证明部分再收窄 gap，不以解析或命令成功代替语义断言。
- 受影响回归、场景三项检查、`make check-docs`、`make quality`、`make test`、`make test-contracts` 全绿且无 skip。

## 前置

审查与既有 `DATASET-REVISION-01` 的范围及文件重叠，不另开同文件并行实施线。

## 不做

不改变自动跟随、检索保留、来源提交保留或紧急清除的任务归属。

## 关闭

2026-10-23 并入 `DATASET-REVISION-01`，未按本文件单独验收。

并入理由：本债的触发条件是“下一次修改 Dataset 版本分配、发布幂等或历史对比入口时处理”，而
`DATASET-REVISION-01` 的自动发修订必然改这三处——服务端取下一个号、按定义判等决定是否增号、
按固定版本服务。本债自己也写着“与 `DATASET-REVISION-01` 的范围重叠审查后并入，避免同文件双线实施”。
它还有一个从未落实的写法：“与 `DATASET-REVISION-01` 的范围重叠审查后并入”，但当时并未真正并入，
仍留在 `todo/` 排队。

同时修正本债的一处定性：原文把自己的性质定为“新功能，按 bug 先做新功能先不做，本轮不改”。这不成立。
[Dataset](../../doc/design/dataset.md) 的进度表把“版本号改为服务端分配”列在近期，并写明当前实现要求
调用方传 `revision` 与“系统生成、不接受指定”不一致——U16 是版本语义本身，不是可选扩展；
`_views.yaml` 也已为 U16、U17 登记精确 gap 指向本债。按“新功能”搁置会让设计目标与实现长期不一致。

承接情况：

- U16（服务端分配、单调不可复用、同定义重放不增号、请求内固定版本）与 U17（两版指针对比、
  不读来源字节、来源不可用仍返回指针差异）四条验收原样并入 `DATASET-REVISION-01` 的`## 并入`。
- “收窄 `.data/scenes/_views.yaml` 的 gap，不以解析或命令成功代替语义断言”保留。
- “不削弱设计或守卫”保留。
