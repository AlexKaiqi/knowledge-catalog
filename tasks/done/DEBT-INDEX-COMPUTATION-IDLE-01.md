# DEBT-INDEX-COMPUTATION-IDLE-01 · 独立回收不再访问的计算缓存分区

## 债

- 位置：`declarativeindex/opensearch/internal/opensearchimpl/embedding_cache.go`、`config.go`，以及实例资源维护装配。
- 信号：过期清理目前由当前模型分区的构建访问触发；模型/端点/凭据域切换后，旧分区可能永不再访问。
- 判定：向量可正确复用，但旧分区不能据此证明空间在有限维护周期内收敛；单分区上限也不是实例总量上限。
- 处置：由实例维护独立、持久续扫旧分区，验证全部归属、原计算票据和过期条件；给出实例总预算及空分区处理，
  不让查询打开触发 IO，不删除仍在使用的库文件，不把未知文件或元数据缺失当作空集合。
- 触发条件：`INDEX-PHYSICAL-01` 当前已在进行，并修改同一批文件，登记后立即并入该主任务。

## 目标

不依赖旧模型再次构建，失去计算保护且到期的缓存能由实例维护有界回收；配置连续切换后空间仍可收敛。

## 依据

[索引物理布局](../../doc/design/index-physical.md)、[工程质量闭环](../../doc/engineering/quality.md)。

## 验收

- 当前模型切换、全部查询句柄关闭、进程冷开后，仍能枚举并回收旧分区；大分区及大量分区持久续扫。
- 未过期计算与并发发布有保护，迟到旧票据不能重建已清数据；未知归属不修补或删除。
- 配置反复切换的实例总容量及逻辑/物理空间收敛有证据；新查询语料中的复制向量不依赖缓存存活。
- 受影响回归、架构、质量和文档门禁通过，结果无 skip。

## 前置

与 `INDEX-PHYSICAL-01` 的计算产物保护、配额及清除接缝一并推进。

## 不做

不更换 embedding 模型，不调整 ANN 语义，不借缓存回收实现 Dataset 保留政策。

## 关闭

未实现独立回收；按同批文件债务归并规则并入 `INDEX-PHYSICAL-01`，该主任务保留上述全部剩余验收。
