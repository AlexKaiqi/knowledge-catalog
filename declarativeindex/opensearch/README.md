# declarativeindex/opensearch


OpenSearch managed projection，属于可丢弃、可重建的检索层，不是 Snapshot authority。

本包是公开注册薄壳（B12，裁决 C）：`Config`、`Env*` 常量、`Check`、`Open` 再导出自
`declarativeindex/opensearch/internal/opensearchimpl`——实现体仅本 adapter 内部可达（A-01）；装配通过插件 Entry 使用本薄壳。

- `declarativeindex/projection/` 将 Entity、Aspect、Member、Relation 编译为完整的类型化对象文档。
- 本包拥有 OpenSearch provider 的完整实现，不另设驱动名。集群若拒绝 OpenSearch 的 PIT 路由和 `index.knn`，同一客户端改用 Elasticsearch 的 `/_pit` 与 `dense_vector`。
- 物理数据使用 generation index；basis、active generation 和状态保存在独立 control index。
- `Config.Namespace` 是稳定、非秘密的实例身份，分别隔离实际 control index、generation 与分页依据。
  私有工作目录不决定物理身份；同一 namespace 换目录仍接纳自己的资源，不同实例必须使用不同 namespace。
  空 namespace 保留既有物理名称、投影摘要与续页格式，供唯一实例接纳旧资源；namespace 不改变对象 Repository 身份。
- 查询使用 PIT + `search_after`，候选返回后必须在同一 basis 回读 Canonical。
- Open 仅校验本地配置，不发送网络请求；首次重建才确保 control index。搜索、关系及 PIT 的超时、
  部分分片失败和提前终止不得变成完整候选；增量每批等待其触及分片可见后才发布。
- 当前提供方版本为 `opensearch-v6-declaration-member-fields`，mapping 为
  `typed-cells-v4-access-faces`，compiler 为 `object-units-v4-member-construction`；
  这些标识进入物理摘要。它保留无损整数游标与纳秒时间排序键；时间键只属于 adapter，
  公开排序元数据使用规范时间。既有物理版本通过原维护机制重建。
- `LoadMetaContext` 在同一 context 读取控制记录并检查其实际 generation 是否存在；缺代返回空 Meta，
  维护可沿原路径重建，真实读取错误仍失败。检查不做全库 count 或 refresh。
- 每次候选读取核对活动 generation/basis；创建 PIT 前后复核控制文档的 CAS 版本，拒绝与增量或
  发布交错的读取。已失效的游标要求重启查询，不跟随新 basis。
- READY 发布响应丢失时先回读控制权威，只有同一物理代及完整意图元数据匹配才恢复成功。
  明确 CAS 拒绝可清理本次未采用候选；无法核对或当前已被其它发布替换时不据此推断从未采用，
  保留该代并在本实例控制索引内登记独立的未确认记录。对账记录写入失败也不允许删除；错误保留
  具体资源身份。后续持久资源管理仍须接管这些记录，不能将此修复当作完整回收闭环已经交付。
- 替换活动生成代前，先在同一实例控制索引内持久保存旧生成代与原依据的保护记录；记录失败则
  不发布新代，既有同名记录必须精确匹配。移除进程内三分钟删除定时器，重开引擎后记录与旧资源
  仍保留。已接受引用沿实际消费者权威释放；具备完整查询覆盖的旧代，只有在已知 READY 替代、
  全部有效保护解除且删除排他持久建立后才回收。旧格式与未确权资源继续保留，迁移期间须计入空间。
- 新候选在创建前登记唯一随机资源身份与十五分钟构建租约；创建、每批 bulk、刷新前先以资源
  记录的 CAS 登记在途请求并续期，确认完成后排空。过期资格不能取得新的写入或发布准入。已准入请求结果
  未知时，即使租约过期仍保留资源；它恢复执行并确认完成后才允许清理，不能把超时当成未发生。
  发布前转入独立保护，已采用和发布不确定的资源不进入候选超时清理。
- `ResourceMaintainer.RecoverResources` 是维护端口，定期 CatchUp 在 READY 需求无变化时仍会调用；
  查询、Open、只读 Reconcile 和仓范围 CatchUp 不触发全局物理回收。恢复只接管本实例正向确权、
  已过期且排空的未发布候选、中断删除，以及显式自有 namespace 内具备完整读者覆盖的无保护历史代；
  删除资格与写入资格使用同一 CAS。删除响应未知
  时保留记录，重启后按原资源身份幂等核对；确认删除后保留拒绝旧写入的控制记录。
  每次至多扫描 2048 条候选，独立持久游标避免早页未决请求阻塞后续清理；未知保护通过维护诊断
  报告具体资源；正常活动 ROOT 与有效声明列在 Protected，未知资格列在 Retained。
  ROOT/独立维护需求解除、生命周期的其余保留政策、旧 namespace 迁移及成员产物复用仍待接入。
  恢复器只接管本版本生成的规范随机代标识，损坏或不明格式留待核对，不能把记录中的通配符、
  多索引表达式或其它未知名称直接交给物理删除。
- Workspace 不进入文档 mapping。上层按 ResolvedDataset 的固定
  `(repository, commit)` 选择 generation 并扇出；多 index、`_msearch` 或绑定不可变 PinID 的
  短期 alias 只允许作为可丢执行优化。

真实容器验证：

```bash
./scripts/e2e-opensearch.sh
```


## 语义向量投影

设置 `KC_EMBEDDING_MODEL` 与 `KC_EMBEDDING_DIMENSIONS`（加 OPENAI_BASE_URL/OPENAI_API_KEY）后，
投影在生成索引里加入 `semantic_vectors` nested 字段，其中每个显式 vector 成员独立保存
成员身份、登记模型与 knn_vector（hnsw/lucene，cosinesimil）。构建批次内以一次 embeddings 调用
处理这些成员声明的输入；text 成员不隐式产生向量。模型或维度未配置的引擎保持纯 lexical 投影，
没有选入可用 vector 成员时语义查询明确拒绝。语义窗口是单次有界 top-K 查询，候选携带 approximate 证据；
这是派生投影，不是第二权威（doc/design/discovery.md）。

控制元数据读取遇到同一控制索引主分片明确处于恢复状态时，在调用者截止时间内最多等待一秒，随后保留真实的不可用结果；只重复只读元数据 GET，不创建索引，也不重试其它提供方错误。

准备资源票据与生成代归属共用资源文档 CAS。签发前后核对完整 READY 元数据及实际介质，
具体生成代的准备保护与增量写入互斥；其他进程同样不能修改被票据固定的语料。准备票据十五分钟
未准入可以失效；准入把上层实际权威与完整候选证据持久保存，失效准备者不能恢复准入。
准入确认丢失仍保留引用，同一票据只能重试完全相同的证据；确认接受后仍持久保护。
增量写入也先取得资源排他，物理或控制完成未知时保留在途保护；未知确权不作空保护处理。
已准入引用按下文的权威围栏流程恢复；已接受引用的唯一采用映射与生命周期释放仍由
`INDEX-PHYSICAL-01` 接入，不能仅按票据过期回收。未确权旧生成代仍须迁移，不能直接签发受保护票据。

资源记录当前使用版本 5，加入普通 ROOT 查询覆盖与历史删除证明。旧版本 1 且无引用、版本 2 的合法发布引用、
版本 3 的合法查询引用及版本 4 的合法续页引用均可沿同一 CAS 升级；账本版本升级不自动取得完整查询覆盖。
未知版本或损坏引用拒绝修改，不能忽略未识别字段再覆盖。启用版本 5 的查询覆盖及历史回收前须排空旧版本读写进程；
同实例的并行工作进程须运行支持该资源协议的版本，资源文档版本检查不替代对旧二进制的部署围栏。

`OpenResources` 为显式 namespace 建立独立的实例维护句柄，构造/关闭没有远端操作，不伪造
Repository 或打开查询代。维护扫描所有已确权资源，因此冷启动后从未查询过的空间也可恢复。
旧空 namespace 不具备排他实例归属，继续只做已打开 scope 的维护，不能当作完成实例库存迁移。

已准入票据的十五分钟期限只安排故障恢复，不直接解除保护，也不由重试顺延。到期后把原证据交给
实际发布权威 resolver；唯一发布收据确认该准备时保护继续，围栏证明未采用时解除该票据，未知则保留并报告。
处置前重新 CAS 核对同一票据、证据及资源状态，并发确认不会被删除；物理语料是否回收另查消费者和生命周期。
候选和引用扫描均以仓身份/生成代稳定翻页，单次最多 2048 资源，耐久游标使前页未知不饿死后页；
超时、部分分片或损坏游标不给完成结论。

资源准入返回成功前，还须建立按完整不透明证据寻址的持久发布映射，保存确切资源、票据和完整
READY 元数据。映射以只创建方式登记，同证据重试核对全身份；响应丢失不解除已准入保护。
冻结前若资源经过普通增量更新，须在无旧引用的资源 CAS 中接管最新元数据，再加入准备票据。

`BindPublication` 读取映射与资源权威，核对同一票据/证据/元数据，在资源 CAS 中复核原发布引用并取得独立查询保护后打开固定视图。
活动指针替换或丢失不改变该视图；计数和 PIT 固定到原代，视图拒绝 Rebuild/Apply/构建、准备和恢复。
Dataset 已接受但资源确认响应丢失时，持有原准入保护的语料仍可查询，查询不补做确认。
缺映射、已解除引用、未知归属或丢失介质明确失败，不用另一 READY 代替代。
旧映射迁移、已发布资源显式修复接管和发布映射自身的生命周期清理继续由 `INDEX-PHYSICAL-01` 交付。

`RepairPublication` 在维护路径观察原映射 CAS 版本，在确切绑定不可用或不满足调用方当前固定兼容合同时调用原固定来源的
准备回调。新资源先持久准入，再在权威资格复核回调中替换映射；并发替换以映射 CAS 排他，
不拿活动指针充当已接受映射。响应丢失后只有介质读回同一完整票据和元数据才恢复成功，
否则保持未知保护。资格检查在准入前拒绝时取消未准入票据。已明确被新映射替换的旧采用票据，
在实际资格已知后由独立引用对账解除；未知或 CAS 失败保留。独立查询/续页租约不随旧采用票据解除。
该步骤不宣称物理代已删除。

查询保护按原请求截止时间与默认 30 秒上限取较早者，期限在取得时持久固定，不续期。
只读视图的元数据、计数与远端操作均检查期限，并继承原请求取消；关闭仅解除该查询引用，
不解除发布引用。关闭失败或进程退出后，由实例维护按原截止时间 CAS 解除过期查询引用，
不调用发布 resolver，也不能将查询引用确认成永久发布保护。此期限只覆盖单次请求，
不替代 Dataset 续页、观察代或检索保留；这些保护仍须分别接入。

`BindPublicationContinuation` 按提供方续页及原采用证据打开原资源，独立于当前发布映射。
续页由原查询取得的资源 CAS 建立，绑定实际逻辑查询范围、生成代及第一次登记的截止时间，
默认宽限两分钟；后续页不续期。期限或范围不能由重算公开游标校验值改写，后台仅按耐久
原期限解除续页引用。新请求先核验有效续页再取得独立单次查询保护，已取得保护的请求不因
续页引用随后退出而提前失效。该入口不读取移动来源、不修复映射，也不恢复已删除的代。

静态 Dataset Search 的外层游标先选择提供方原续页，再按原 Meta 完整校验查询与读取范围；
无当前映射的冷开实例仍可继续原语料。关系提供方使用相同续页保护，关系外层认证后再选择原代。观察代续页和 Dataset 生命周期期限组合仍由主任务继续交付。

`ContinuationSealStore` 在本实例及物理读取范围的控制记录中保存独有签名材料，只创建一次。
首次查询可准备密钥；已有游标验证只加载原材料，缺失、损坏或暂不可读均失败，不补造进程
随机密钥。并发创建及确认丢失以实际控制记录选定赢家。返回的 `ContinuationSealer` 只做本地
HMAC 验签/签名，执行预算结束后封装已有续页不再依赖远端调用；它不授予语料访问或延长保护。
元数据中缺少原材料时旧游标须重新开始，不能按当前生成代替换。

观察代替换的原续页截止时间登记在新 READY 指针的同次 CAS 中；候选构建或发布失败不改变当前代期限。
后续发布携带仍有效的旧代截止时间，不能刷新它们；过期项可从准入映射中退出，但这不授予物理删除权限，
在途请求仍由独立资源租约保护。期限不是不可变旧生成代元数据的一部分，避免清理过期期限时改变旧代身份。
此登记是 `INDEX-PHYSICAL-01` 的观察准入基础；上层仓与 Dataset 的查询消费、生命周期及资源释放接入仍在推进，
不能仅因该映射存在就宣称已支持跨观察代续页。

`BindObservation` 已实现提供方的上述观察视图：以当前指针确认新请求，以原提供方续页及耐久租约恢复旧代，
在资源 CAS 取得保护后复核观察权威；异空间游标在后端读取前拒绝。新续页仍保持原租约身份和截止时间，
查询视图拒绝维护写入。该提供方回归不等于上层仓与 Dataset 查询已完成切换。

资源发布记录保存实际编译计数，成功增量更新同步确认后的完整 READY 元数据后再解除写入排他。
早期拥有记录的初始零计数可从同一生成代的不可变保留记录或仍匹配的 READY 指针只读恢复；不借另一代
的计数，不在查询中修补耐久归属。缺少精确依据时失败。这只兼容计数，不代表未确权旧命名空间已迁移。

新生成代在创建时登记查询覆盖，READY ROOT 承诺普通全文、关系、语义查询及残值 MATCH 分析使用独立的有界请求租约；
续页使用另一种耐久租约，原期限不续延。它们不借用具名发布的保护，不能由普通 ROOT 游标恢复发布视图。
ROOT 在途请求排斥原地写入；普通 ROOT 续页只保护物理存在，不冻结可变来源，源依据改变仍按原合同要求
重启查询。保护通过请求 context 注入，不能改共享引擎字段，也不能借另一个具体引擎的已关闭保护。

历史代进入删除前核对实际自有 namespace 的 READY 替代 ROOT，完整覆盖标记和全部声明；用资源 CAS
排空已到期的有限租约并持久登记替代依据与 DELETING，再复核 ROOT 后删除。有效接受、准入、查询或
续页保护均阻止删除。ROOT 缺失/不可读、未排空写入或旧读者覆盖未知时保留；删除响应丢失在重开后
按同一资源身份恢复，完成后保留 DELETED 记录，旧写入不能重建。并发回收者幂等处理同一删除。

旧空 namespace 不开放历史 ADOPTED 回收。它的实例归属和旧进程围栏须先显式迁移；将旧记录触碰为
版本 5、或看到它已非活动，都不构成新查询覆盖与删除资格。当前活动 ROOT 及独立维护需求的终止另由
消费者权威交付，本机制不把当前 ROOT 没有发布引用解释为它已无消费者。

实例恢复扫描包含 PUBLISHING：只有实际自有 READY ROOT 与候选的完整元数据、物理身份和计数一致，
并满足原查询覆盖承诺，才在资源 CAS 中补记 ADOPTED。原发布者迟到的确认幂等保留已有资源状态与引用；
正向确认不重写 ROOT，也不覆盖后续增量元数据。计数不符、缺失或不可读均继续保留；
单凭不同 ROOT 或租约到期也不能证明发布拒绝。本路径修复引擎提交后的确认缺口，不替代 Dataset 发布接受或引用交接。

对非当前 READY 的过期 PUBLISHING 候选，只有显式自有 namespace、完整查询覆盖、无待决物理请求且无
保护声明时，恢复器才可尝试拒绝围栏：以实际现存 ROOT 的原版本 CAS 写回同一内容，确认排除原发布者
的迟到 CAS 后，再经资源权威进入删除。有效构建租约不改 ROOT；ROOT 缺失、身份/状态未知、围栏冲突或
响应丢失时保留候选，不创建 ROOT、不推断删除完成。下次恢复须重新取得并确认实际围栏。


流式构建会话实现 `PreparedRebuildSession.CommitResource`：在进入 PUBLISHING 的同次资源 CAS 中
登记独有 PREPARED 票据，再发布 ROOT 并确认 ADOPTED。恢复确认、ROOT 替换或原构建者迟到重试均
保留同一票据；成功返回的句柄固定原提交的完整 READY 元数据，不按当前 ROOT 重新选择。失败未返回的
准备保护仍持久保留；只有从未准入的 PREPARED 声明可以按原期限退出。过期 PUBLISHING 回收先排除

显式 namespace 且有运行目录的引擎惰性使用实例级 bbolt 保存计算结果；打开查询句柄不创建目录或库。
同一耐久库的分区登记与计算记录在一个事务中变更，维护可枚举不再配置的旧模型。模型、维数、适配实现与
实际端点共同确定语义兼容摘要；缓存另以凭据域摘要隔离。凭据轮换保持同一模型语料的兼容性，凭据文本
不进入路径或记录。缓存复用实际向量，复制到新语料后，成员、来源提交和对象摘要仍属于当前构建。

向量结果的登记/发布经过生成代资源准入，增量写入复用原耐久写排他。成员提取和构造在显式准备路径
以独立计算票据及原请求上下文登记，只有同一未过期 nonce 才能持久发布。关闭或过期的计算票据不能覆盖新计算者，
显式错误模型响应拒绝，失败仅取消本次未发布票据。记录严格拒绝未知字段，以内容摘要核验实际向量。
实例的成员值及全部向量模型共享 64 MiB 逻辑预算，模型登记预留 512 字节也计入预算；容量不足时继续独立计算。
READY 一小时无使用后可退出，计算票据十五分钟到期；缓存期限不延长查询语料或续页期限。

`ComputationMaintainer.RecoverComputations` 由实例维护传入显式运行目录，与当前模型或查询句柄无关。

尚未初始化的实例不创建库；已有实例目录丢失介质时报告未知，不按空集合处理或补造。显式新构建须重新
