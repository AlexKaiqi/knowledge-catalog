# 发现与声明式索引

discover 回答“有哪些对象，哪个适合这个任务”。已知对象身份时直接读；不知道时先搜索，再按同一
版本回读。声明式索引是实现搜索的插件，适合某一类对象数量很多的场景。

## 目标

- 按 Schema 的声明搜索、过滤、排序，声明是唯一的索引写法。
- 索引只给候选，内容必须按同一版本回读，避免“直接读”和“搜到后读”变成两种结果。
- 未就绪、不支持、预算不足、确实没有匹配，四种情况明确区分。
- 索引可以丢失重建，不是内容权威。
- 发布成功后，后台自动维护索引；源提交不因索引失败撤销。

## 从声明到结果

1. 固定本次范围（某个 Dataset，或调用者可读的仓）和版本。
2. 结合 Schema 的访问声明、插件实际支持的能力和预算，选择合法的执行路径。
3. 插件返回候选坐标。
4. 对象层按同一版本回读，必要时补判条件。
5. 返回命中、依据，以及结果是否完整。

声明了字段不等于插件支持它，插件支持也不等于这一版已经就绪。三者都满足、并且调用者有权，才能执行。

## 完整性

- 两个条件分别能执行，不代表合在一起也能。先各取少量命中再求交可能漏掉结果，无法证明时拒绝。
- 必需的部分没有能力执行时默认失败。只有调用者显式允许尽力而为，才返回部分结果并如实说明。
- 跨仓查询在各仓的固定版本上执行，保留来源后合并。排序要能证明归并顺序；不同打分系统的分数不揉成一个概率。
- 关系遍历是有界的：固定范围，按类型、角色、方向扩展到显式跳数上限，越界停下并标明。
- 语义召回（semantic、hybrid）只在已准入的范围内召回，结果标为近似；缺向量能力时失败，不降级冒充。

## 不做什么

不提供任意字符串查询语言、SQL、正则或通配；没有“列出全部对象”；分面和总数不随搜索返回，需要时
做成独立能力。这些边界保证每次查询都能说清覆盖了什么。

## 翻页与预算

- 一个后端页不等于一个产品页，补判淘汰后要继续取。预算用尽时报告限制和续页位置。
- 续页沿用原查询和原版本。原依据不可用时要求重新开始，不接到新的索引上。
- 取消要向下游传播。

## 索引维护

- 通知缩短延迟，对账保证恢复。通知丢失、重复、乱序或进程重启后，最终结果等价于重建。
- 只有解释规则连续时才增量更新；Schema 的访问声明变了，受影响的部分要重新判断。
- Dataset 发布时，按冻结的来源版本准备索引，全部准备好才接受新版；固定的 Dataset 不跟随来源的最新版本。
- 每个实例的进度、失败和退出相互隔离，一个阻塞不影响另一个。
- 搜索只检查是否就绪，不触发构建，也不靠扫描全仓弥补。

## 插件与作用域

声明式索引是插件 `declarative-index`，按 Schema 的访问声明对所有用该 Schema 的对象生效，仓可以
关闭。按类型跨仓发现，同一对象的多个方面按 `object_id` 合并，未就绪或已关闭的范围单独列出，见
[插件](plugins.md)。

## 入口

`kc search`、`kc relations`、`kc traverse` 执行查询；`kc plugin declarative-index help` 说明字段声明的
含义和用法。

## 用例

场景树按 `discovery#U<编号>` 关联验证入口和缺口。先写用例、跑基线，再改接到绿。

### U1：字段

文本、数字、日期和缺值的检索排序，核对结果集合和值；未声明、类型错误、有歧义、不支持的组合
明确拒绝；缺值、不适用和取值失败分开说明。

### U2：按类型生效

两个仓里有同一类型的对象，Schema 声明了索引字段。两个仓的对象都能被同一查询找到；关闭插件的仓
不参与。插件没装、撤权或越界明确拒绝。核对范围、总预算、排序与续页归并；访问概览与实际生效的
插件一致，帮助只读。

### U3：更新恢复

增删改对象和 Schema，通知丢失、重复、乱序，重启或删除索引；自动恢复的结果和重建等价，
固定的 Dataset 不跟随 HEAD。

### U4：原子与失败

命中版本 a 后，仓或 Dataset 推进到 b；对象值、Schema 和范围仍属于 a，或者明确失败。
构建、准备、接受失败或接受前取消，都不公开半成品，保留当前发布版。

### U5：分页回读

第一页或动态命中之后源更新，续页和回读沿用原依据。引擎失败、坏坐标、错版本、正文或原观察丢失、
过期、换实例都明确失败；发布失败保留原观察，不冒充零命中。

### U6：隔离退出

两个插件实例用同一引擎服务同一个仓，一个阻塞或失败不影响另一个。后台身份不随请求变化。
构造失败按逆序释放；退出时先停新请求，等在途请求与维护结束，资源只释放一次。

## 代码位置

| 目录 | 负责 |
|---|---|
| `discovery/` | 通用查询合同、结果与续页、跨来源组合、业务命令 |
| `declarativeindex/projection/` | 查询与物理引擎（OpenSearch） |
| `declarativeindex/control/` | 构建、更新、切换、恢复 |
| `declarativeindex/plugin/` | 插件装配 |
