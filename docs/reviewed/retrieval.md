# 检索：计划、候选与同依据回读

Retrieval 帮助使用者找到知识，不重新定义知识。它根据一次请求的范围、版本和能力选择
查询路径，定位候选并按相同依据回读。声明式索引解释允许怎样查，索引控制维护可用投影；
本篇解释一次查询怎样正确完成，不承担后台构建和恢复。

## 从声明到候选，再回到知识

查询计划固定本次范围与版本，结合逻辑访问声明、提供方能力和预算选择合法路径。
计划需要解释哪些条件由提供方完成、哪些需回读后补判，以及能承诺怎样的覆盖。
声明了字段不等于任意提供方都能查询它，提供方支持也不等于指定版本已经就绪。

索引只交付候选坐标。公开命中还要按相同依据回读知识；物理引擎保存的正文、摘要或分数
不能替代这一步。读取走 Knowledge 的同一解释路径，避免“直接读”和“搜到后读”变成两种知识。

Dataset 查询在固定文件范围内执行；跨仓按各自固定版本取候选并保留来源，不按每个 Dataset
复制整套索引。关系查询同样先找关系对象再回读，不因端点引用自动扩大查询范围。
模型筛选或重排只能处理已允许读取的候选，不改变身份，不把不同来源的分数伪造成统一概率。

## 完整性必须可证明

提供方要对实际查询说明能力，不能从单个条件可用推导任意组合都可用。候选有冗余时，
只有完整回读并完成等价补判，才能据此声称完整；可能遗漏、预算不足和提供方故障须如实区分。

未就绪不是零命中。候选与正文依据不匹配时拒绝结果，不能用部分结果标记掩盖版本错误。
调用方明确允许的近似或有限覆盖，也不能绕过授权与同依据回读。分页在原查询依据上继续，
失去该依据时要求重新开始，不能悄悄接到新投影。

动态查询的覆盖、新鲜度和重读能力分别证明；遍历完旧观察不能证明源当前没有匹配项。
包括零命中在内的时效承诺由动态消费合同决定，检索层不能通过一个完整性标记补造它。

## 组合条件与多来源不能靠猜测拼接

全文、过滤、排序及其组合需要提供方给出实际能力证明。两个条件分别可执行，不表示把
各自有限候选合在一起就等价于完整组合；例如先各取少量命中再求交，可能漏掉真实结果。
无法证明时明确拒绝，不能把这种捷径报成精确查询。

跨仓查询在各成员固定版本上执行，再保留来源地合并。显式排序需要相容的类型与可证明的
归并顺序；相关度保留各提供方依据，不把不同打分系统揉成一个未经校准的概率。
同分结果需要稳定处理，否则分页会重复或跳过对象。

外部来源能够直接完成查询时，可以只提供检索端口，不被迫伪造本地索引维护能力。
源端下推仍需证明查询范围、授权、候选依据和回读方式；当前只有一个提供方的实现，不限制
这个边界，但也不能因此宣称已有通用的多提供方成本规划。

## 分页与预算属于执行语义

候选被补判淘汰、去重或范围过滤后，执行器需要继续取下一批；一个后端页不等于完整的
产品页。候选预算、后端访问和执行时间应有界，独立来源共享本次查询的总预算。
预算用尽但执行依据仍有效时，按公开合同报告限制与续页位置，不能伪装成已遍历全部范围。

跨来源归并时缺少必要的下一项，就无法证明全局顺序。执行器不能仅把最快来源的结果
当作完整排序页；停在哪、还缺什么，需要可解释。续页继续原查询与版本，不能换范围、
声明或活动投影后还沿用旧位置。

正文缓存可以减少同版本回读，但缓存未命中仍按原依据回源。动态观察按原观察依据回读，
两者不能混用。候选坐标错误、原依据不可用或回读失败是执行失败，不是普通候选不匹配。

## 与后台和权限的交接

检索只检查能力与就绪，不启动构建。新内容已发布但投影未追上时，精确读取仍可以成立，
搜索如实说明不可用。后续恢复由索引控制负责，查询不能扫描全仓弥补缺能力。

请求先建立授权与范围，再访问候选和正文。Dataset 的范围过滤、单仓发现与正文交付的
区别，以及动态源授权由权限体系规定；查询必须落实这些决定，不能以“索引里已有”为理由
绕过它们。授权裁剪的语义也不能用来掩盖候选版本错误。

选定候选与正文分离，需要承担同依据回读的成本，换取索引可替换且不会变成第二份知识权威。
选定如实报告能力、覆盖与预算，否决“有一些结果就算成功”、查询时同步建索引，以及
把引擎保存的摘要直接当成知识正文。物理优化需要守住这些保证，规模资格仍由实际负载证明。

## 方向性用例

### U1：新知识已发布，但搜索尚未就绪

接入方能按固定版本读取新正文，消费者的搜索明确报告对应能力尚不可用。
系统不能返回成功的零命中，也不能要求本次查询现场重建。

### U2：第一页候选都未通过补判

查询继续读取后续候选，或在预算耗尽时报告仍未完成。不能把第一批被淘汰等同于全范围
零命中，也不能返回补判之前的假阳性结果。

### U3：多个来源的能力或速度不同

查询说明哪些条件和范围能够正确执行。一个必要成员无法提供能力时不静默忽略；缺少排序
所需候选时不把最快成员的局部结果冒充全局顺序。不能把独立分数伪装成统一概率。

### U4：查询过程中投影推进

后续页与命中正文仍属于原依据；原依据不可用则明确终止。不能把第一次候选和第二次
最新正文拼成看似一致的结果。

### U5：对候选做语义重排

使用者仍能追溯每个结果的原身份、版本与提供方证据。模型未判断、判断后未入选和请求失败
可以区分；模型不能凭空加入未检索、未授权的知识。
