# 检索：计划、候选与同依据回读

Retrieval 帮助使用者找到知识，不重新定义知识。它根据一次请求的范围、版本和能力选择
查询路径，定位候选并按相同依据回读。声明式索引解释允许怎样查，索引控制维护可用投影；
本篇解释一次查询怎样正确完成，不承担后台构建和恢复。

## 从声明到候选，再回到知识

查询计划固定本次范围与版本，结合逻辑访问声明、提供方能力和预算选择合法路径。
计划需要解释哪些条件由提供方完成、哪些需回读后补判，以及能承诺怎样的覆盖。
声明了字段不等于任意提供方都能查询它，提供方支持也不等于指定版本已经就绪。

索引只交付候选坐标。公开命中还要按相同依据回读知识；物理引擎保存的正文、摘要或分数
不能替代这一步。读取走 Knowledge 的同一解释路径，避免“直接读”和“搜到后读”变成两种知识。

Dataset 查询在固定文件范围内执行；跨仓按各自固定版本取候选并保留来源，不按每个 Dataset
复制整套索引。关系查询同样先找关系对象再回读，不因端点引用自动扩大查询范围。
模型筛选或重排只能处理已允许读取的候选，不改变身份，不把不同来源的分数伪造成统一概率。

知识集范围是请求事实，不是知识字段，也不是另一份索引权威。Snapshot 工作索引按
Repository、basis commit 与提供方 revision 共享，物理文档不保存组合范围标识；同一投影
可以被多个请求范围复用。多 index、跨 index 搜索或绑定固定 pin 的短期 alias 只是可丢弃的
执行优化，不能成为组合、版本或授权的权威；动态投影对应 binding generation 与观察依据，
不能混入按 Repository commit 组织的索引表。

## 完整性必须可证明

提供方要对实际查询说明能力，不能从单个条件可用推导任意组合都可用。候选有冗余时，
只有完整回读并完成等价补判，才能据此声称完整；可能遗漏、预算不足和提供方故障须如实区分。
必需部分没有合法执行能力时默认失败关闭；只有调用方显式允许 best-effort，才可以跳过并
返回部分结果与如实声明——访问声明未覆盖的字段不构成“扫描兜底”的理由。等价补判必须
保持整棵原请求的表达式语义：不能只重判被放宽的叶子而忽略组合中原本精确的条件，也不能
把字符串包含当成与分词后的词项匹配等价；无法证明等价之前，不得接入按超集提供候选或
源端下推的提供方，“业界都有下推”不构成跳过证明的理由。

未就绪不是零命中。候选与正文依据不匹配时拒绝结果，不能用部分结果标记掩盖版本错误。
调用方明确允许的近似或有限覆盖，也不能绕过授权与同依据回读。分页在原查询依据上继续，
失去该依据时要求重新开始，不能悄悄接到新投影。

动态查询的覆盖、新鲜度和重读能力分别证明；遍历完旧观察不能证明源当前没有匹配项。
包括零命中在内的时效承诺由动态消费合同决定，检索层不能通过一个完整性标记补造它。

## 组合条件与多来源不能靠猜测拼接

全文、过滤、排序及其组合需要提供方给出实际能力证明。两个条件分别可执行，不表示把
各自有限候选合在一起就等价于完整组合；例如先各取少量命中再求交，可能漏掉真实结果。
无法证明时明确拒绝，不能把这种捷径报成精确查询。

跨仓查询在各成员固定版本上执行，再保留来源地合并。显式排序需要相容的类型与可证明的
归并顺序；相关度保留各提供方依据，不把不同打分系统揉成一个未经校准的概率。
同分结果需要稳定处理，否则分页会重复或跳过对象。

模型重排是同一固定 pin 上的薄物理组合，不是逻辑检索程序：携带 continuation 或超出候选
与字节预算的请求在调用模型之前拒绝，不通过自动分批改变全局排序。SEARCH 先产生有界
候选窗与真实的 lane、local rank 证据；物理 rank 与分数进入审计证据，不进入模型请求。
非确定性重排不得塞进 SEARCH 的续页依据。

外部来源能够直接完成查询时，可以只提供检索端口，不被迫伪造本地索引维护能力。
源端下推仍需证明查询范围、授权、候选依据和回读方式；当前只有一个提供方的实现，不限制
这个边界，但也不能因此宣称已有通用的多提供方成本规划。

## 关系遍历是有界类型化扩展

一跳关系查询返回命中的关系对象，邻接的命中坐标属于命中的关系对象本身。把邻接扩展成
多步是第二层能力：遍历在请求开始固定范围（Dataset 清单或单仓 pin），沿类型化关系步骤
（类型、端点角色、方向）扩展到显式跳数上界，返回按对象去重的到达集合，并逐边披露存储
仓与 commit。它不枚举全部路径，也不承诺最短路径。授权前置到每次扩展动作，越界止步并
显式标记（粒度见权限体系），遍历不能成为扩权或披露范围外拓扑的通道。遍历共享请求级
预算，超限标记不完整并给出可续位置，循环按节点去重。无界遍历与任意图查询语言被否决；
图引擎只能作为类型化请求的编译目标，是派生、可重建的，不成为第二权威。

## 召回策略扩展：semantic 与 hybrid 已选定合同方向

SEARCH 的召回策略是请求级闭集：lexical（默认，省略不改变既有请求语义）、semantic、
hybrid。semantic 在候选资格内做向量召回：资格仍由固定范围、当前授权与 typed filter
先于召回判定，召回不得扩大资格或绕过范围检查。向量投影是按仓从已声明的 text 字段派生
的 k-NN 投影——派生、可重建、由投影控制链维护，不是第二权威，也不是第四种字段访问
声明；新增向量声明不回填既有对象，「写入到可召回」的异步间隔进入结果依据。查询向量在
请求期向 embedding 提供方取得，输入 digest、模型身份与索引间隔进入证据。semantic 与
hybrid 结果一律标记 Approximate 并披露近似来源，complete 条件不因此放松；缺少向量投影、
embedding 能力或间隔不可接受时失败关闭，不静默降级为 lexical 冒充。hybrid 的融合策略
另行裁决，选定前只保留策略名，不得实现。

## 检索能力有明确边界

SEARCH 代数不做无约束字符串查询语言，也不做通用 RQL 或 SQL：调用方拼装任意谓词会让
覆盖证明失去对象。无界补集（NOT）与空扫描依赖封闭全集或浏览面；目录产品提供它们，是
因为把目录当作封闭语料且浏览是 UI 起点——本系统没有对象实例 LIST，这两者不能伪装成
可证明的定位。GLOB、REGEX 与调用方自带通配不进入代数，CONTAINS 是字面子串而非模式
匹配；typo、fuzzy、stemming 的跨提供方统一语义不作承诺。Facet 与总数统计不作为 SEARCH
返回：界面需要时做成独立的投影能力并标明 exact 或 approximate。有界 BROWSE（源卡片与
类型目录）是另一条产品面，不是 SEARCH 的空扫描，也不得解释成对象实例全集。这些边界
不得通过改变 MATCH、EQ 或返回正文含义的方式偷偷越过。

## 分页与预算属于执行语义

候选被补判淘汰、去重或范围过滤后，执行器需要继续取下一批；一个后端页不等于完整的
产品页。候选预算、后端访问和执行时间应有界，独立来源共享本次查询的总预算。
预算用尽但执行依据仍有效时，按公开合同报告限制与续页位置，不能伪装成已遍历全部范围。

调用方取消要向下游传播，取消后不再发起新一轮访问；不支持取消的外部端口只能在调用
边界检查，不得虚报 I/O 已被中断。空页只有在读取位置或消费进度发生可保存变化时才构成
进展，仅重新包装同一位置不算；预算不足且无法前进时明确失败，不为超时编造未经验证的
游标。准备阶段没有可验证的固定计划时同样明确失败。

跨来源归并时缺少必要的下一项，就无法证明全局顺序。执行器不能仅把最快来源的结果
当作完整排序页；停在哪、还缺什么，需要可解释。续页继续原查询与版本，不能换范围、
声明或活动投影后还沿用旧位置。

正文缓存可以减少同版本回读，但缓存未命中仍按原依据回源。动态观察按原观察依据回读，
两者不能混用。候选坐标错误、原依据不可用或回读失败是执行失败，不是普通候选不匹配。

## 与后台和权限的交接

检索只检查能力与就绪，不启动构建。新内容已发布但投影未追上时，精确读取仍可以成立，
搜索如实说明不可用。后续恢复由索引控制负责，查询不能扫描全仓弥补缺能力。

请求先建立授权与范围，再访问候选和正文。Dataset 的范围过滤、单仓发现与正文交付的
区别，以及动态源授权由权限体系规定；查询必须落实这些决定，不能以“索引里已有”为理由
绕过它们。授权裁剪的语义也不能用来掩盖候选版本错误。

选定候选与正文分离，需要承担同依据回读的成本，换取索引可替换且不会变成第二份知识权威。
选定如实报告能力、覆盖与预算，否决“有一些结果就算成功”、查询时同步建索引，以及
把引擎保存的摘要直接当成知识正文。物理优化需要守住这些保证，规模资格仍由实际负载证明。

## 方向性用例

### U1：新知识已发布，但搜索尚未就绪

接入方能按固定版本读取新正文，消费者的搜索明确报告对应能力尚不可用。
系统不能返回成功的零命中，也不能要求本次查询现场重建。

### U2：第一页候选都未通过补判

查询继续读取后续候选，或在预算耗尽时报告仍未完成。不能把第一批被淘汰等同于全范围
零命中，也不能返回补判之前的假阳性结果。

### U3：多个来源的能力或速度不同

查询说明哪些条件和范围能够正确执行。一个必要成员无法提供能力时不静默忽略；缺少排序
所需候选时不把最快成员的局部结果冒充全局顺序。不能把独立分数伪装成统一概率。

### U4：查询过程中投影推进

后续页与命中正文仍属于原依据；原依据不可用则明确终止。不能把第一次候选和第二次
最新正文拼成看似一致的结果。

### U5：对候选做语义重排

使用者仍能追溯每个结果的原身份、版本与提供方证据。模型未判断、判断后未入选和请求失败
可以区分；模型不能凭空加入未检索、未授权的知识。
