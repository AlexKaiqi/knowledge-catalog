# 声明式索引：插件重构

## 目标与契约

把 Home 直接装配的索引改为独立 `declarative-index` 插件。Repo 配置并限定作用域，Server 装配；写后维护和查询使用同一仓贡献。Dataset 只组合固定来源；实例可服务多个已配置的 Repo。

Schema 字段的 `access` 与类型规定怎样查；声明允许、实现支持、版本就绪且获授权才可执行。保持已有声明方式、检索原语与语义。

## 能力与承诺

- **查询：**按声明执行文本检索、过滤、排序及已有关系/遍历；返回命中、依据及是否完整。不支持、未就绪或失败不能算零命中。
- **准备版本：**准备 Dataset 的冻结来源；全部必需索引准备好才接受新发布版，失败或接受前取消保留旧版。
- **自动维护：**收到内容/声明变化后更新；遗漏通知、重启或索引丢失后恢复。报告进度与失败；源提交后允许暂时不可查。
- **一致读取：**系统固定仓/Dataset 的版本和范围，贯穿索引、Schema、对象层回读与续页。索引查 a，正文读 a；动态命中读原观察。依据不可用就失败，不读最新值补缺。
- **范围与隔离：**系统先核权限和范围；实例隔离数据、任务、进度并管理启停，故障不阻塞独立实例。

源提交不因索引失败撤销。承诺按结果、发布状态与用例验收；说明不证明当前就绪。

## 命令与目录

`kc plugin declarative-index help` 只读说明条件、保证与用法。执行走 `kc search`、`kc relations`、`kc traverse` 和已有运维入口。

实现、说明、测试集中于 `declarativeindex/`：`projection/` 查询及引擎，`control/` 构建/更新/切换/恢复，`plugin/` 装配，`cli/` 插件说明与专属运维调用。控制经维护接口用索引，查询不依赖控制；CLI 经 Server。

通用查询合同、选择/组合和业务 CLI 归 `discovery/`。命令沿[CLI](cli.md)。

## 验收用例与执行顺序

先写用例、跑基线，再改接至绿；失败核原因、发布依据及恢复结果。

### U1：字段

文本/数字/日期/缺值的检索排序核对集合和值；未声明、错类型、歧义、不支持组合拒绝；缺值、不适用和取值失败分开。

### U2：来源选用

R1 配置 A、R2 配置 B，D 组合固定来源；维护、准备/查询/运维按来源调用。同源不同组合使用同一贡献，未配置仓不参与；缺实现/贡献、撤权/越界拒绝。核验范围、总预算、排序/续页归并；概览与 Repo 配置一致，帮助只读。首批假设贡献无冲突。

### U3：更新恢复

增删改对象/Schema，丢/重/乱序通知，重启/删索引；自动恢复结果等价重建，固定 D 不跟 HEAD。

### U4：原子与失败

命中 a 后推进仓/Dataset 至 b；对象值、Schema、范围仍属 a 或明确失败。构建/准备/接受失败及接受前取消不公开半成品，保留旧发布版。

### U5：分页回读

第一页/动态命中后源更新；续页/回读沿原依据。引擎失败、坏坐标、错版本、正文/原观察丢失、过期/换实例明确失败；发布失败保留原观察，不冒充零命中。

### U6：隔离退出

A/B 同引擎服务同仓，A 阻塞/失败不影响 B。后台身份不随请求变化。构造失败逆序释放；退出停新请求、等在途与维护，资源释放一次。

对象与插件层验收后实施；部署另验。
