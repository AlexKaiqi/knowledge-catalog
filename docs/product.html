Knowledge Catalog · 写给接入方

愿意把知识接进来，是因为权还在你手里

被发现，但正文仍由你授权。 新版本可以灰度；访问能追查到哪个 Agent 替谁读了哪一版；出事能按版本复现。 你接完，别人用自己的 Agent 就能用——不必再做一套消费产品。

核心价值

1

能被发现，正文仍由你授权

别人能看见你的知识源、按类型找、按主题搜。谁能读正文，仍是你说了算。撤权后，旧任务也带不走新的读权。

2

版本、审计、溯源

新知识可以灰度，主用的人不受影响。

能查出哪个 Agent 替哪个用户、何时读了哪一版哪条知识。

出事能复现：Agent 记 trace，版本都在，可以拉分支对照当时那一版。

3

接进来就能被检索

稳定知识按你声明的字段被找到，不用自建搜索。

瞬时数据也能被找，不会写脏版本史。

4

读得够快，仓也撑得住

效果P95P99
读一条已发布知识500ms2s
本机检索250ms1s
共享检索1s3s

正式目标约 100 万表、3300 万对象；规模档点读 P99 100ms。读可用性 99.9%，检索/写入 99.5%。

单实例功能已合格。百万表压测和多实例尚未当已交付。

5

你接完，别人就能用

个人用户和 Agent 搜、读、挂进项目。你不用再做门户，也不用为他们再包一层产品。

核心概念

你发布的是知识源里的版本。目录只让人发现这个源。正文读权仍在你这条仓上。

你的源系统 / 草稿 / Connector │ │ 你定义结构，经 Writer 发布 ▼ 知识源 Repository Catalog Snapshot 版本仓 只登记：有这个源、有哪些知识集 对象 / Aspect / 来源信封 不存正文 │ │ 有你的授权，才读得到正文 ▼ 消费：统一搜 / 读 / 溯源，可选只读文件视图 个人用户和 Agent 用同一套知识，不必你再做门户

交进去的是知识，不是目录或源表

手册、指标、表合同都是有稳定身份的对象。路径怎么改，这条知识还是它。结构你定，平台按你的声明来找。

已确认的、此刻的、发生过的，分开放

要留下来治理的进版本仓。此刻的水位在外面观察。发生过的事按流水看。别把瞬时值写进历史。

目录让人发现你，读正文仍过你的仓

接进来之后

你发布并授权之后，人和 Agent 就能用。

1. 发现 看见你的源说明和知识类型；看不见你没放开的正文
2. 选定 选一个知识集，或这次任务临时组合你的源
3. 冻结 这一次任务钉在同一组版本上
4. 使用 统一检索 / 读取 / 溯源；可选只读 VFS

不用先猜关键词，也不用翻别人的仓库。

当前做到哪

单实例 Server / Client 已经能走通发布、检索和读取。共享服务试点有条件可用；多实例生产尚未验收。 Stream 窗口查询等仍见 docs/MVP_ACCEPTANCE.md。

它不做什么

别拿它当这些东西

  • 不是「打开某个目录就算接上知识」的开关。
  • 不是把仓库里所有对象列给你的清单。
  • 不是搜索失败后去扫全仓、假装还有结果。
  • 不是发布知识之前必须先建一个知识集。
  • 不是让你直接改 git / 数据库 / 索引来「发布」。
  • 公开产品名是 Knowledge Catalog，不是 Loom。

接入方要盯的

知识接进来之后，权、身份、访问账和被怎么找到，都还在你这边。

认证

人、Agent、服务怎么登录。身份由认证器注入，不能在请求里自报。

 权限

谁能发现你的源，谁能搜、谁能读正文。看见不等于读到。

 访问可观测

哪个 Agent 替谁、何时读了哪一版哪条知识。账不写回知识、不改权限。

 运行可观测

读/搜要多久、可用性怎么算。延迟预算和告警在这里。

 发布与结构

Schema、身份规则、源说明。接进来怎么验收、怎么演进。

 切面与检索声明

按切面写、按声明被找到。命中后再读正式内容。

 从源采集

源系统的变化怎么变成可发布的知识。采集不会自动发权。

 瞬时数据

此刻的值和流水不要写进版本史。仓里只放观察声明。

 版本与灰度

不同知识集可钉不同版本。新知识可以先灰度。

 合入门槛

候选版本要凭什么证据才能变成已发布。

 写之后通知外面

发布可以触发外部系统，但不另开一条写知识的路。
规模 能撑多大的仓 压测资格线

百万表目标和点读门槛。

消费方要盯的

个人用户和自己的 Agent 怎么找到知识、怎么用、访问会不会被记下。

找知识、用知识

先看见有什么，再搜、再读。构建 Agent 也走同一套。

 认证

你是谁、Agent 代理的是谁。没有身份就没有发现和读取。

 权限

能看见源，不等于能读正文。没有读权就看不到内容。

 检索

按主题和条件定位候选，命中后再回读这一版的正式内容。

 访问可观测

你的搜和读会留下证据。Agent 侧也可记 trace，按版本能复现。

 钉住版本

这一次任务用同一组版本。换版本是显式动作。

 读瞬时

当前水位和流水按观察来，不和已发布版本混成一把钥匙。

 接到自己的 Agent

统一的搜、读、挂文件。Agent 是你的，知识仍是接入方的。
