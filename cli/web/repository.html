发布与维护

知识内容通过 Writer 发布。创建完成后，可在客户端使用这个仓库身份继续操作。

  1. 准备源说明、Schema 和知识对象，运行 检查草稿。
  2. 使用生成的变更集发布，再按同一版本回读和检查来源。
  3. 查询发布状态时保留原 command-id，重试不会另建一笔发布。
客户端命令

kc writer receipt --command-id <原命令ID>

kc catalog repo list --mine

管理地址不授予访问权。每次读取和操作都使用当前授权。
