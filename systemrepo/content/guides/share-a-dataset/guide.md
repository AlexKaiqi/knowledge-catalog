# 向消费者交付 Dataset

1. 发布者有选择与分享目标来源的权限，已明确消费任务。
2. 选择确定版本的文件或子目录，选入知识解释所需声明，规划交付路径。
3. 检查路径冲突并定义发布范围，核对已接受的版本。
4. 按资源与动作合同给消费者 Dataset 消费权；消费者解析并检出固定范围。
5. 成功证据：消费者仅得到发布文件，保留来源坐标。源仓更新后重新发布，消费者明确采用新版。

所需能力：[组合与采用 Dataset](../../capabilities/datasets/definition.md)、[查询与管理授权](../../capabilities/permissions/definition.md)、[精确读取与复核](../../capabilities/read-knowledge/definition.md)。
