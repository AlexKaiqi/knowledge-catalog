# Dataset

命名、版本化的跨仓文件交付范围，从确定版本选择文件或目录，组织成消费目录树。

发布固定来源版本与清单，源仓后续提交不改变已发布版。字节与来源保持，目标目录不生成对象身份。解释所需的 Schema 和其它依赖须被选入。
