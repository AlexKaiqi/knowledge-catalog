# 登记空间

每套服务唯一的来源登记与 Dataset 发布状态。它不是可创建或切换的独立业务对象。

登记空间 说明哪些来源已登记以及采用哪些版本与文件范围。发现库存不意味着成员仓正文可读，组合不需要先解释 Schema。
