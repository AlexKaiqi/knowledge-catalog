# 接入知识来源：使用与核对

连接明确的目标服务。已有仓使用接入能力，托管仓由部署供给策略创建；以回执核对仓身份和登记。解除登记不等于物理删除源仓。

选择 [调用入口](entrypoints.yaml) 后，先运行对应叶子 help 查看当前版本的操作数、参数和输入形状。系统仓保留任务语义，完整命令合同由 help 提供。
